# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus on the work. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

Report unacceptable behavior to the maintainer, [@Luce-Florian](https://github.com/Luce-Florian), through a [private security advisory](https://github.com/Luce-Florian/proctor/security/advisories/new) if it must stay confidential. The maintainer will review every report and may remove content or block a participant.
