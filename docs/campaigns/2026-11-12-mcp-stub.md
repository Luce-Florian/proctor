- **Stubs**: 0 trials `other`. Every stub connected under `srt`, listed its tool, and answered every call from a rule of the case: `mcpStubFallbacks` is 0 in all 12 trials with a stub.
- **Plugin naming**: in `plugin-server`, the agent called `mcp__plugin_dbtools_pgsql__get_object_details`, the name the plugin's own server would have. The skill found its tool without knowing it was a stub.
- **Grounding**: with a stub, the answer quotes the index the case stubbed (`orders_customer_id_idx`) or its absence. Without a server, the agent cannot answer.
- **The 2 passes of `without-server` on `index-exists` are false positives**: the answers start with "No — I can't determine this yet". The yes/no regex sees a `no`. A judge criterion, or a stricter pattern, tells an abstention from an answer.
- **Without a server, the agent reads files that do not exist**: `Read` refuses `db.sqlite3`, `database.sqlite` and `app.db` as binary files before checking they exist, in an empty workspace. The agent took that as proof of a database it could not query. This is Claude Code's behavior, not the harness's.
